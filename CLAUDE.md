# CLAUDE.md

Este repositório é uma base de instruções para pesquisa e validação de direitos da pessoa com deficiência no Brasil.

## Ao responder perguntas sobre o tema

- Siga o [`SKILL.md`](SKILL.md): triagem, mapeamento de módulos, busca, validação e resposta.
- Use as ferramentas de busca na web para confirmar toda citação em fonte oficial antes de apresentá-la como certa.
- Respeite a legenda de status dos módulos (V, S, C). Itens S e C devem ser reconferidos.

## Ao editar o repositório

- Toda norma nova entra com: citação exata, resumo em uma frase, URL oficial, status (V/S/C) e data da verificação.
- Atualize [`fontes/registro-de-verificacao.md`](fontes/registro-de-verificacao.md) sempre que conferir ou corrigir algo.
- Não apague histórico relevante: se uma norma foi revogada, registre a revogação e a norma que a substituiu.
- Texto em português do Brasil, linguagem simples, sem travessões decorativos.
- Não inclua dados pessoais de clientes ou casos concretos.
